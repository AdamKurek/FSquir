# Fillsquir Privacy Notes

Fillsquir stores level progress, settings, and best-placement snapshots on the player's device.

If leaderboard sync is enabled, the app sends the record server:

- install id
- level, seed, and rules version
- achieved coverage percentage
- placed-fragment proof used to verify the score
- client attempt id and achievement timestamp

The project does not intentionally collect names, email addresses, contacts, precise location, advertising identifiers, or payment data.

Before store submission, replace this note with the public privacy policy URL and verify the deployed record server retention policy.
